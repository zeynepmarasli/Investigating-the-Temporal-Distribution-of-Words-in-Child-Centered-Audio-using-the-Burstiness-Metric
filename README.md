# Investigating the Temporal Distribution of Words in Child Centered Audio using the Burstiness Metric
analyses for paper of same name submitted to Infant Behavior and Development Special Issue - From Daily Life to Data: Synergies in Sensing and Computation for Studying Infant Behavior in Context

OSF repository: https://osf.io/4xv7a/overview 
## 1. get_burstiness_data.ipynb
   - Jupyter notebook for extracting burstiness values from full daylong audio recordings, sampled daylong audio intervals, and CHILDES
   - saves burstiness values as csvs

## 2. correlations_and_regressions.Rmd  
   - R markdown file of statistical analyses presented in paper

## 3. visualizations.Rmd 
   - R markdown file of figures presented in paper for Analyses 1 and 2

## 4. eventplotfigures_analysis3.ipynb
   - Jupyter notebook for figure presented in analysis 3 and additional exploratory visualizations
